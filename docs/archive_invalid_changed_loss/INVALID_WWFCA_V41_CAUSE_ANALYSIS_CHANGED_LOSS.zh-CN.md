# WWFCA v4.1 未提升主指标的原因分析

## 核心判断

v4.1 已解决 v4 将高频空间信息平均掉的问题，但新的高频直达路径同时保留了大量缠绕跳变和噪声。LL 交叉注意力的实际调制幅度很小，尚不足以从这些高频中筛选出与干净解缠相位有关的部分。因此，模块主要表现为一个并行 DWT 卷积分支，而不是有效的 LL 引导频率选择器。

## 1. GFS 的输入高频与目标高频不匹配

在 GFS128 训练集前 500 个样本上进行 Haar DWT：

| 数据 | LL RMS | LH RMS | HL RMS | HH RMS | 三个高频平均/LL |
|---|---:|---:|---:|---:|---:|
| 干净解缠真值 | 26.7097 | 0.4341 | 0.4185 | 0.0111 | **1.08%** |
| 缠绕输入 | 2.9974 | 1.2575 | 1.2428 | 1.1067 | **40.11%** |

GFS 真值由平滑曲面组成，真实高频能量很低；缠绕输入中却存在大量由 `2π` 跳变和噪声形成的高频。v4.1 保留空间高频的能力越强，如果门控不能可靠识别其来源，就越容易把无用高频送回 HF 主干。

这也解释了指标方向：Mean-aligned MAE、PGE 和重缠误差略有改善，但范围对齐 AU、U3-NRMSE 和 U3-SSIM没有改善。分支能修正少量局部误差，却会轻微扰动整体平滑形状和动态范围。

## 2. LL 注意力没有真正主导高频选择

最佳权重相对初始化的参数变化如下：

| 参数 | 相对变化 |
|---|---:|
| Query 投影 | 0.325% |
| Key 投影 | 0.280% |
| Value 投影 | 0.403% |
| 相对位置偏置 | 0.019% |
| 温度参数 | 0.085% |
| 距离参数 | 0.011% |
| 高频融合卷积 | 37.82% |
| 输出投影 | 517.06% |
| 门控投影 | 12.10% |

训练主要改变了高频融合卷积和输出投影，Query、Key、位置、温度和距离几乎没有学习。这说明模型依赖高频直达卷积降低损失，没有充分使用 LL 查询关系。

真实样本上的门控统计为：

- 门控均值：0.5026；
- 门控标准差：0.0281；
- 门控范围：0.4101 至 0.6020；
- `alpha`：0.1006；
- 最终高频乘子均值：1.0005；
- 最终高频乘子标准差：0.00565；
- 最终高频乘子范围：0.9819 至 1.0205。

虽然门控具有空间变化，但乘上 `alpha` 后通常只对高频进行约 0.5% 的波动调制，最大也只有约 ±2%。所以 v4.1 中“保留高频”已经生效，“LL 选择高频”仍然很弱。

## 3. 高频辅助损失占比高于预期

第 32 轮：

- 主监督损失：`1.1546e-5`；
- 原始高频损失：`2.8886e-4`；
- 乘以 0.01 后：`2.8886e-6`；
- 加权高频项相当于主监督损失的 **25.0%**。

系数 `0.01` 看起来很小，但两个损失的自然尺度不同，因此高频项实际并不轻。对于干净目标高频比例只有约 1%的 GFS，这会过度强调本来很弱的细节。off 对照也使用相同损失，所以配对仍然公平；但该目标会促使 v4.1 的专用高频分支更积极地拟合微小高频，其中一部分可能是样本特有误差。

## 4. 主干仍能替代分支

冻结主干时，v4.1 将验证 U3-NRMSE 从固定 HF 的 `0.007168` 改善到 `0.007098`，约 0.98%。这表明并行分支有表达能力。

联合微调后，off 对照逐渐追平，最佳验证值只差 `4.53e-6`。HF U-Net 的普通卷积足以学习大部分修正，WWFCA 没有提供独有且稳定的物理信息。六个测试条件全部未在 U3-NRMSE 上胜过 off，说明验证集的微小领先属于可忽略波动或轻微验证过拟合。

## 5. 当前消融还不能单独证明交叉注意力

现有对照是：

- `v4.1`：高频卷积直达路径 + LL 交叉注意力门控；
- `v4.1_off`：整个新增分支关闭。

它可以判断整个模块是否有效，却不能区分收益来自高频卷积还是交叉注意力。下一轮至少需要三个严格对照：

1. HF/off；
2. 只有高频卷积直达路径，不使用 LL 注意力；
3. 高频卷积直达路径 + LL 注意力门控。

只有第 3 组稳定优于第 2 组，才能证明交叉注意力本身有效。

## 建议的下一步

### 第一优先级：让高频来源与相位物理一致

不要直接加强当前高频幅度。先使用圆周相位差抑制人工缠绕跳变：

`d_x = atan2(sin(psi[x+1]-psi[x]), cos(psi[x+1]-psi[x]))`，

`d_y = atan2(sin(psi[y+1]-psi[y]), cos(psi[y+1]-psi[y]))`。

将圆周梯度投影到特征通道，与 DWT 高频共同构成 Key/Value，或用于生成可靠性掩码。这样 `2π` 边界不会被误认为强高频细节。

### 第二优先级：监督“选择位置”，而不是单纯增大高频

用干净真值的梯度幅度构造训练期目标门控：

`G_target = Normalize(|grad(phi_clean)|)`。

加入小权重门控监督，使 LL 注意力学习哪些位置需要高频修正。推理时不需要真值，仍由网络产生门控。该监督应只训练门控关系，不直接强迫预测图像增加高频。

### 第三优先级：降低高频损失实际占比

将高频损失控制在主监督的 5%以内。固定权重可先从 `0.002` 开始，或使用动态权重：

`lambda_hf = min(lambda_max, 0.05 L_supervised / stopgrad(L_HF))`。

GFS 的 HH 真值几乎为零，可先只监督 LH 和 HL，避免对角高频噪声主导。

### 第四优先级：增强门控作用，但保持有界

在高频来源经过圆周梯度约束后，再把 `alpha` 初始值从 0.1 提高到 0.25，并监控乘子标准差。目标是让乘子标准差达到约 2% 至 5%，同时保持残差/主分支 RMS 不超过 1%。直接提高 `gamma` 不合适，因为当前总残差幅度已经足够。

## 不建议的修改

- 不建议直接提高 `gamma` 或取消1%能量约束；
- 不建议立即增加更多插入层；
- 不建议只通过降低注意力熵迫使其变尖锐；
- 不建议继续强调普通 DWT 高频损失。

这些操作会增强输入中的缠绕跳变和噪声，却不能解决高频来源与干净目标不一致的问题。
