# 方法对比训练预算协议

## 结论

论文主表采用“各方法充分训练、验证集选模”，不强制相同轮数。不同模型的 batch size、每轮更新次数、学习率调度和训练阶段不同，相同 epoch 不能代表相同优化预算。另设统一 200 轮的预算控制实验，用来回答相同数据暴露量下的比较；两张表分别报告，不混为一组结果。

训练集、验证集和测试集固定不变。训练轮数与停止规则在查看测试结果前确定；最佳权重只按验证集对齐 MAE 选择，测试集只在最终权重确定后评估一次。所有方法报告实际 epoch、optimizer updates、见过的样本数、GPU 小时、峰值显存、参数量、FLOPs 和推理延迟。

## 主表训练长度

| 方法 | 建议训练长度/上限 | 选择规则 | 依据 |
|---|---:|---|---|
| 传统方法 | 0 | 无权重 | Itoh、质量引导、最小二乘等无需训练 |
| DLPU | 100 轮；最多延长到 150 | 验证集最佳 | 原仓库默认 100 轮、batch 32 |
| SQD-LSTM | 100 轮；最多延长到 150 | 验证集最佳 | 原仓库默认 100 轮；本项目完整实验最佳点在第 57 轮，继续到 200 轮没有稳定收益 |
| PUNet | 300 轮 | 验证集最佳 | 官方仓库默认 300 轮；当前 200 轮任务只能算缩短预算结果 |
| Uformer | 250 轮 | 验证集最佳 | 原仓库默认 250 轮，含 3 轮 warm-up 和余弦调度 |
| Restormer | 300,000 optimizer updates | 验证集最佳 | 官方 Restormer 按迭代数训练，常用配置为 300k updates；不要硬换成固定 epoch |
| U3Net | 700 轮：500 自恢复 + 200 蒸馏 | 仅在第 501–700 轮中按验证集选模 | 原仓库完整阶段配置；不能按比例压缩成 143+57 |
| HF diffusion | 300 轮上限 | 验证集最佳 | 本项目基线没有可直接照搬的 PU 官方训练轮数，先采用与 PUNet 相同的充分训练上限 |
| FDU / 本次改进 | 300 轮上限 | 验证集最佳 | 与 HF 基线使用相同训练长度、batch、优化器和学习率调度，避免为本文方法单独增加预算 |
| DDC、WWFCA 及其他消融 | 300 轮上限 | 验证集最佳 | 所有扩散消融与完整模型共享完全相同的训练协议 |

Restormer 的 epoch 换算公式为 `ceil(300000 / ceil(N_train / batch_size))`。在 20,000 张训练数据上，batch 4、8、32 分别约为 60、120、480 轮。因此 Restormer 应在图表横轴中同时给出 updates，不能只比较 epoch。

HF、FDU 和消融的 300 轮是本项目预注册上限，不是原论文复现值。先观察验证曲线；若最后 40 轮仍持续改善，应把所有扩散变体统一延长相同轮数，而不能只延长表现较好的变体。

## 统一预算附表

所有非分阶段深度模型训练 200 轮，保持各自能够稳定运行的 batch size，同时报告每轮更新数和总 updates。U3Net 只执行 200 轮自恢复，名称写为 `U3Net-SR (200 epochs, budget-limited)`；不执行提前蒸馏。传统方法仍为零训练。

这张表控制每个样本被访问约 200 次，但不控制 optimizer updates 或 GPU 时间。若需要回答计算预算公平性，再增加等 GPU 小时曲线：横轴使用累计 GPU 小时，纵轴使用验证集指标，读取各方法在相同时间点的最佳验证性能。

## 收敛和选模规则

1. 每轮保存训练 loss、验证指标、学习率、更新次数、吞吐和权重；测试指标不写入训练循环。
2. 非分阶段模型在计划上限内以最低验证集对齐 MAE 的 checkpoint 为最终权重。连续 30 轮相对改善不足 0.1% 可作为“已趋于收敛”的标记，但主表仍应遵守预先规定的上限或统一延长规则。
3. U3Net 必须完成 500 轮自恢复后再建立教师并训练 200 轮；最终 checkpoint 只能从蒸馏阶段选择。额外报告第 500 轮教师结果，说明蒸馏带来的增减。
4. 每种深度方法至少训练 3 个随机种子，主表报告逐图指标在种子间的均值和标准差。若成本不足，先完成单种子全方法表，再补种子，不能只给本文方法补种子。
5. HF、FDU、DDC/WWFCA 消融必须使用相同随机种子列表和数据顺序，并保持除被消融模块外的配置一致。

## 本项目当前结果的使用边界

- SQD-LSTM 的 200 轮结果可用，最佳验证权重在第 57 轮；论文中可报告所选轮次，同时说明最大预算为 200。
- 旧 PUNet 结果来自错误的小模型，已经隔离，不能用于论文比较；官方结构正在重新训练。若任务只跑到 200 轮，它属于统一预算附表，主表还需补到 300 轮。
- 当前 U3Net 的 143+57 轮结果发生 CAM 饱和且教师已退化，不能进入正式主表。需按 500+200、FP32、数据增强和逐样本 SNR 重训。
