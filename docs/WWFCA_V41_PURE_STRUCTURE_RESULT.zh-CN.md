# WWFCA v4.1 纯结构消融结果

## 实验有效性

本报告只使用重新训练的纯结构实验。`wwfca_v41` 与 `wwfca_v41_off` 的损失均为原始 HF 干净 `x0` 预测 MSE，没有 DWT、梯度、SSIM或其他辅助损失。35轮中每一轮都满足：

`train_total - train_supervised = 0`。

此前加入高频损失的实验已移入 `experiments/results/invalid_changed_loss_20260916`，不参与本报告。

## 最佳权重结果

| 方法 | 最佳轮次 | 验证 U3-NRMSE | 六条件平均 U3-NRMSE | 六条件平均 U3-SSIM |
|---|---:|---:|---:|---:|
| v4.1 off | 32 | 0.00636115 | 0.00666070 | 0.98541871 |
| v4.1 | 34 | **0.00635824** | **0.00664331** | **0.98543975** |

v4.1 相对 off：

- 测试平均 U3-NRMSE 降低 `1.739e-5`，相对改善约 **0.261%**；
- U3-SSIM 提高 `2.104e-5`；
- Mean-aligned NRMSE 改善约 **0.421%**；
- Mean-aligned MAE 改善约 **0.264%**；
- PGE 改善约 **0.800%**；
- Range-aligned AU 提高约 `0.0271`。

## 各条件主指标

| 条件 | off U3-NRMSE | v4.1 U3-NRMSE | 结果 |
|---|---:|---:|---|
| 0 dB | **0.01010010** | 0.01011011 | v4.1 变差 |
| 5 dB | 0.00661712 | **0.00660335** | v4.1 改善 |
| 10 dB | 0.00606503 | **0.00603698** | v4.1 改善 |
| 20 dB | 0.00575077 | **0.00572362** | v4.1 改善 |
| 30 dB | 0.00571928 | **0.00569282** | v4.1 改善 |
| clean | 0.00571190 | **0.00569297** | v4.1 改善 |

改善出现在5 dB到clean的五个条件，0 dB时退化。说明新增高频残差更适合中低噪声和平滑输入，在强噪声下会把部分噪声当作有用高频。

## 训练阶段分析

前15轮冻结HF主干时，v4.1在15轮中全部优于固定off，平均验证U3-NRMSE差为 `-2.91e-5`。这证明新增分支本身能够学习有效修正。

后20轮联合微调时，v4.1平均差变为 `+4.14e-6`，只在6轮优于off。普通HF主干在开放训练后可以吸收大部分分支收益，v4.1优势并不稳定。各自按验证集选择最佳权重后，v4.1测试平均值仍略好，但效应量较小。

## 残差行为

移除能量惩罚后，分支参数自动学习到：

- `gamma ≈ 0.02938`；
- 注入残差/主分支 RMS 约 `2.5%`；
- 注意力熵约 `0.955`；
- 门控空间标准差约 `0.0125`。

这说明此前1%能量惩罚确实限制了分支表达。不过当前2.5%的幅度在0 dB产生退化，提示后续应按噪声强度自适应控制残差，而不是继续统一增大门控。

## 交叉注意力是否有效

最佳权重相对初始化的主要参数变化：

| 参数 | 相对变化 |
|---|---:|
| Query | 0.273% |
| Key | 0.266% |
| Value | 0.220% |
| 相对位置偏置 | 0.011% |
| 温度 | 0.080% |
| 距离强度 | 0.003% |
| 高频融合卷积 | 43.91% |
| 输出投影 | 813.60% |

训练主要改变了高频卷积和输出投影，LL交叉注意力核心参数几乎不变。

进一步进行了推理期门控消融：保留训练好的方向高频卷积、融合、输出投影和gamma，只把注意力门控固定为 `G=0.5`。

| 模型状态 | 平均 U3-NRMSE | 平均 U3-SSIM |
|---|---:|---:|
| 原训练 v4.1 | 0.00664331 | 0.98543975 |
| 固定门控 G=0.5 | **0.00664209** | **0.98544277** |

固定门控后没有下降，反而略有改善。因此当前约0.26%的收益主要来自方向高频卷积残差，不能归因于LL查询高频的交叉注意力。

## 可采用的结论

1. 不修改损失时，整个v4.1分支相对off取得约0.26%的平均U3-NRMSE改善，并在六个条件中的五个条件占优。
2. 改善幅度较小，0 dB仍退化；单次随机种子不足以证明统计显著性。
3. 当前交叉注意力门控没有贡献可测收益；有效部分是方向高频卷积和残差注入。
4. 因此不能把这组结果写成“WWFCA交叉注意力有效”，只能写成“频率残差分支带来小幅改善”。

## 下一步消融要求

正式证明WWFCA需要至少三个同损失、同训练协议的模型：

1. HF/off；
2. 方向高频卷积残差，但门控固定为0.5；
3. 方向高频卷积残差 + LL交叉注意力门控。

第3组必须稳定优于第2组，才能把收益归因于交叉注意力。针对0 dB，可让gamma由`sigma`条件控制，在高噪声时自动减小高频注入。
