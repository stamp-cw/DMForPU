# WWFCA 在 GFS128 前 100 轮略低于 HF 基线的原因与改进方案

## 结论

当前结果不能说明“交叉注意力一定无效”。HF diffusion 的最佳 U3-aligned NRMSE 为 0.011297，WWFCA-only 为 0.011503，差距为 1.83%。这个差距较小，而且逐轮验证使用了不同的扩散采样随机种子。应先用固定采样种子和多个重复种子复测，再判断差异是否稳定。

现有对比也不是严格的单变量消融。HF 使用 `UNet2DModel`；WWFCA 使用 `UNet2DConditionModel` 派生的 FDUNet，同时改变了中间块、加入空间自注意力和前馈层，并将参数量从 11.33M 增至 13.91M。因此，当前差异不能全部归因于 WWFCA 分支。

## 数据与训练证据

1. GFS 的目标相位非常平滑。对完整训练集做正交 Haar 分解后，目标相位的高频/低频能量比约为 0.0005。
2. 缠绕输入的高频/低频能量比在 clean、30、20、10、5、0 dB 下分别约为 0.216、0.216、0.254、0.458、0.825、1.714。噪声越大，高频能量越占优势。
3. 缠绕输入和解缠目标的原始 Haar 高频相关性在各噪声条件下都接近 0。这个统计不能直接代表网络中间特征，但说明输入高频主要由缠绕跳变和噪声构成，而不是目标表面的真实细节。
4. WWFCA 当前使用 `LL` 作为 Query、拼接后的 `LH/HL/HH` 作为 Key 和 Value。对于 GFS，这容易让低频结构主动聚合不可靠的高频信息。
5. WWFCA 在第 100 轮的训练 MSE 为 0.000144，低于 HF 的 0.000188，但 U3 NRMSE 反而略高。这更像训练目标和最终相位指标不一致，而不是模型没有拟合训练集。
6. WWFCA 第一轮 U3 NRMSE 为 0.1166，优于 HF 的 0.1737，说明它前期收敛较快；后期优势消失，符合高频分支缺少约束、逐渐拟合干扰成分的现象。

## 实现层面的限制

- WWFCA 一共出现在最后一个下采样块、mid block 和第一个上采样块中，共约 6 个 Transformer block。对只有 4500 张训练图的 GFS128 来说，注入次数偏多。
- 小波子带在 `M/2` 分辨率完成注意力后，通过 nearest interpolation 放回 `M` 分辨率。它复制每个低分辨率 token，不能像逆小波变换那样恢复方向和位置细节，可能产生块状和平滑偏差。
- 注意力输出经 LayerNorm 后以固定系数直接加入残差，没有可学习的零初始化门控。随机初始化的频率分支从训练第一步就会扰动主干。
- 配置中的 dropout 为 0，AdamW 的 weight decay 也为 0。`3_ttas.md` 所述的 Dropout 在当前实验中实际上没有正则化作用。
- `sigma` 在模型 `forward` 中被删除，WWFCA 不知道输入属于 clean、30 dB 还是 0 dB，也不知道何时应抑制高频。
- 当前 scheduler 的 `prediction_type` 是 `sample`，损失也是预测归一化干净相位 `x0` 的 MSE。当前实验并不是噪声 `epsilon` 预测。两种方法仍然公平地使用相同目标，但这与“在噪声预测网络中加入交叉注意力”的原始实验表述不一致。
- 非重叠窗口没有 shifted-window 或重叠融合，窗口边界之间只能依靠已有空间自注意力间接通信。

## 优先实施顺序

### 1. 先修正评测，不重新训练

- 固定验证采样种子，不再使用 `20000 + epoch`。
- 对 HF 和 WWFCA 的候选权重使用完全相同的初始噪声，至少重复 5 个种子，报告均值和标准差。
- 分别统计 clean、30、20、10、5、0 dB，确认 WWFCA 是否只在低噪声或高结构场景有效。
- 用 5、10、20、50 个采样步复测。当前只使用 5 步，可能掩盖注意力分支在迭代去噪中的作用。

### 2. 建立真正的单变量消融

- 使用同一个 FDUNet 主干建立 `frequency_branch_off` 和 `frequency_branch_on`。
- 两者保留相同的 ResNet、自注意力、FFN、通道数、训练种子和参数初始化；唯一差别是频率残差门是否启用。
- 增加参数量相近的卷积残差分支，判断收益来自频率交互还是单纯增加容量。

### 3. 将 WWFCA 改成可安全退化为基线的残差分支

建议采用

`Y = X + alpha(t, sigma, E_H/E_LL) * F_wwfca(X)`，

其中 `alpha` 初始化为 0。这样模型起点等价于关闭 WWFCA，只有在验证有效时才逐渐使用频率分支。门控应接收扩散 timestep、数据噪声 `sigma` 和频带能量比；0 dB 或高扩散噪声时自动减弱高频注入。

### 4. 调整频带交互方向和重建方式

- 优先测试 `高频 Query、LL Key/Value`，让不可靠的高频位置从稳定低频结构获取上下文。
- 同时测试双向版本，但分别设置独立的零初始化门控；不要无条件执行 `LL <- H`。
- 保留 LL、LH、HL、HH 四个子带，通过可学习的子带修正后使用 Haar IDWT 恢复空间特征，替代 nearest interpolation。
- 为 LH、HL、HH 添加方向标识或独立投影，避免把三个方向只当作一个宽通道向量。

### 5. 减少插入位置并增加正则化

- 第一组实验只在 mid block 放一个 WWFCA，再分别增加 down 和 up block。
- 使用 5% 到 10% attention dropout、`1e-4` weight decay、5 到 10 个 epoch 的 warmup。
- WWFCA 分支学习率可设为主干的 0.25 到 0.5 倍，并继续使用梯度裁剪。

### 6. 让训练目标对应最终相位质量

在现有 `x0` MSE 上增加小权重的辅助项：均值对齐相位 L1、相位梯度一致性和重缠绕圆周一致性。初始建议为

`L = L_x0 + 0.05 L_grad + 0.02 L_circular + 0.02 L_mean_aligned`。

这些权重需要小规模消融确定。若论文明确要求噪声预测，应把 HF 和 WWFCA 同时改成 `epsilon` prediction 并从头训练，不能只修改 WWFCA。

## 推荐的最小实验矩阵

| 变体 | 目的 |
|---|---|
| 同主干、频率门关闭 | 严格控制组 |
| 当前 `LL <- H`，零初始化门控，mid-only | 判断安全残差和插入数量的影响 |
| `H <- LL`，零初始化门控，mid-only | 验证交互方向 |
| 双向门控 + IDWT，mid-only | 验证完整改进 |
| 双向门控 + IDWT + phase auxiliary loss | 验证损失对最终指标的影响 |

所有变体先训练 60 到 100 轮筛选，使用固定的 5 个验证采样种子。只有稳定优于严格控制组的变体再训练到完整轮数。

## 已实施的第一阶段改进

已新增 `model/fdunet/wwfca_v2.py`，并启动 100 轮严格配对筛选：

- `wwfca_v2_off`：HF 的同一 `UNet2DModel` 主干，保留完整 v2 参数但关闭频率残差；
- `wwfca_v2`：启用 mid-only 的 v2 频率残差；
- 两组均为 11,550,081 个参数，使用相同随机初始化、数据顺序、噪声、warmup 和 weight decay；
- v2 使用 `H <- LL`、方向子带嵌入、Haar IDWT、5% dropout，以及 timestep/SNR 条件的零初始化门控；
- 验证采样种子固定为 20000，每轮保存权重和全部指标；
- 第一轮两组训练 loss 均为 0.02321，U3 NRMSE 分别为 0.118866 和 0.118865，符合初始严格等价预期。

## 56 轮诊断与停止决定

共同前 55 轮中，HF、v2-off、v2 的最佳 U3 NRMSE 分别为 0.016602、0.016594 和 0.017653。v2-off 与 HF 相差 0.05%，但启用频率分支后比 v2-off 差 6.38%。分别为每项指标寻找最佳轮次时，HF 赢 14/16 项，v2-off 仅以不到 0.05% 的幅度赢 U3 RMSE/NRMSE，v2 没有赢得任何一项。

第 56 轮权重显示条件门控已经失去“小残差”性质：各 SNR 和 timestep 下，`abs(alpha)` 的通道均值为 0.39–0.64，21%–49% 的通道超过 0.8，最大值接近 1。门控最后一层权重范数从第 1 轮的 0.083 增至第 56 轮的 4.952。当前的全学习率、未归一化 timestep embedding 和无幅度上限使零初始化只能保证第一个优化步骤前的等价性，不能限制后续增长。

clean 条件还暴露了噪声编码问题。代码把 `sigma=0` 截断到 `1e-6` 再取对数，得到约 -13.8；30 dB 则约为 -3.34，造成 clean 与有限 SNR 间很大的输入间断。第 56 轮 clean 的平均门幅约 0.62，反而高于 0 dB 的约 0.43。

因此 v2-off 在第 61 轮、v2 在第 56 轮停止，逐轮权重全部保留。下一版本应使用 `log1p(sigma)`、归一化条件输入、幅度限制为 0.05–0.1 的 LayerScale、频率分支较低学习率，并对门控幅度增加正则项。当前版本继续到 100 轮的实验价值不足。

## WWFCA v3

v3 已按诊断结果实现：`log1p(sigma)` 连续噪声编码、条件 LayerNorm、最大 0.1 的频率残差、0.01 门控平方正则、频率支路 0.1 倍学习率、前 10 轮完全关闭门控、第 11–30 轮线性放开。训练日志逐轮记录门控均值/最大值、饱和比例和注入残差/主干 RMS 比。

`wwfca_v3` 与 `wwfca_v3_off` 均为 11,551,107 个参数，训练 50 轮并使用固定验证种子。为降低 CUDA 并发风险，两者顺序运行；v3-on 先运行，随后自动运行严格控制组。全部完成后自动生成配对指标表、测试集结果和门控诊断曲线。

## v3 完成后的梯度诊断

v3 最佳验证 U3 NRMSE 为 0.017772，off 为 0.016594。六个测试条件的平均 U3 NRMSE 分别为 0.018791 和 0.017487，v3 比 off 差 7.46%。v3 仅在 0 dB 好 1.45%，在 5 dB 到 clean 差 5.98%–12.63%。

门控没有饱和，而是形成了冷启动死支路。模型使用

`Y = X + s * 0.1 * tanh(g(c)) * F(X)`。

当 `g(c)=0` 时，频率网络参数的梯度乘以零门值，因此 `F` 完全得不到任务梯度；门控最后一层只能通过随机初始化的 `F(X)` 获得很小的间接梯度。第 10 轮权重在 `s=0.05` 下的实测结果为：主干梯度范数 0.879、门控最后一层 `3.1e-8`、门控早期层 0、频率分支 0。第 41 轮主干梯度为 0.0212，门控最后一层 `2.0e-7`，频率分支仍只有 `2.3e-10`。

第 41 轮未经门控的频率输出 RMS 约为主干的 6.6%，本身不是零；但实际注入比例只有 `3.5e-7`。门控正则值只有 `2.5e-9`，所以正则项不是塌缩主因。零初始化、0.1 幅度因子、渐进系数和 0.1 倍支路学习率相乘，使任务梯度小到无法启动支路。主干随后独立降低损失，留给适配器的残差越来越小，后期更难恢复。

## 推荐的下一版方向

不再从头训练零门控适配器。使用 HF 第 299 轮权重建立严格配对微调：control 与 adapter 从同一个权重开始。adapter 使用非零 LayerScale（建议 0.03–0.05）、最大 0.1，不使用把门值拉向零的正则；先冻结主干训练适配器 5 轮，再以主干 `1e-5`、适配器 `5e-5` 到 `1e-4` 联合训练 15–25 轮。正则目标改为只在注入残差 RMS 超过主干 1% 时惩罚，而不是惩罚门值本身。

结构上，当前 Q/K/V 都来自同一 bottleneck 特征，只是频带间自注意力，没有提供新的观测信息。下一版应让 Query 来自扩散去噪特征，Key/Value 来自独立的缠绕相位条件编码器（`sin(psi), cos(psi), sigma`）。LL 作为稳定上下文，输入高频能量只生成可靠性 mask，不直接作为 Value。相位解缠的主要困难是全局周期和低频范围恢复，因此适配器应允许修正 LL/全局尺度，而不是只通过高频 IDWT 残差修改细节。
