# WWFCA-v4.3：先验证高频，再检索高频

## 结构

输入主干特征记为 `X0`。主干原下采样输出为：

`X = Down(X0)`。

对 `X0` 做 Haar DWT，将三个方向高频 `LH/HL/HH` 分别经过深度卷积和逐点卷积，再拼接融合：

`H = Fuse(Conv_lh(LH), Conv_hl(HL), Conv_hh(HH))`。

第一阶段验证高频，由 `H` 查询主干语义 `X`：

`S = Attention(Q(H), K(X), V(X))`，

`C = sigmoid(Conv([H, S, |H-S|]))`，

`H_v = H * (0.5 + C) + eta * S`。

验证门以接近 `C=0.5` 的小幅非零权重初始化；`eta` 初始为 0.05，给验证注意力提供直接且稳定的梯度。主干支持的高频被增强，不受支持的高频被抑制。

第二阶段检索高频，由 `X` 查询经过验证的高频库：

`R = Attention(Q(X), K(H_v), V(H_v))`。

保留局部高频旁路，防止全局注意力平均掉空间细节：

`H_r = H_v + beta * R`，其中 `0 < beta < 0.5`。

最后进行残差注入：

`Y = X + gamma * Conv_out(GN(H_r))`，其中 `0 < gamma < 0.1`。

两个注意力都采用余弦相似度、二维相对位置偏置和距离先验。

## 公平验证协议

- 使用 HF diffusion epoch 299 权重初始化主干；
- 前 15 轮只训练新分支，后 20 轮以 `1e-6` 学习率联合微调主干；
- 新分支学习率依次为 `1e-4` 和 `5e-5`；
- 损失严格保持 HF clean-x0 MSE，不加入频率损失或能量正则；
- 固定训练、验证和扩散采样随机种子；
- 每轮保存权重，以验证集 U3 对齐 NRMSE 选择最佳权重；
- 与 `wwfca_v41_off`、`wwfca_v41_noattn` 和 `wwfca_v41` 比较完整六条件测试结果。

## GFS128 验证结果

四组均使用相同 HF epoch 299 初始化、相同随机种子、相同 clean-x0 MSE 和 35 轮训练。按验证 U3 对齐 NRMSE 选择最佳权重。

| 方法 | 最佳轮次 | 验证 U3-NRMSE | 六条件平均测试 U3-NRMSE |
|---|---:|---:|---:|
| v4.1-off | 32 | 0.00636115 | 0.00666070 |
| 方向高频，无注意力 | 34 | 0.00635731 | 0.00664358 |
| 旧 v4.1 注意力 | 34 | 0.00635824 | 0.00664331 |
| v4.3 验证后检索 | 34 | **0.00635562** | **0.00664258** |

v4.3 相对 off 的平均测试 U3-NRMSE 改善 0.272%；相对无注意力方向卷积只改善 0.015%，相对旧 v4.1 只改善 0.011%。相对无注意力版本，SSIM 仅增加 0.00000183，Mean-aligned NRMSE 反而恶化 0.008%。

最佳轮次的结构诊断为：

- `gamma=0.02938`，注入残差 RMS 约为主干特征的 2.49%；
- 验证注意力归一化熵 0.933，检索注意力归一化熵 0.964；
- 验证门均值 0.50077，空间标准差只有 0.000744；
- 验证尺度由 0.0500 变为 0.04996，检索尺度由 0.1000 变为 0.09968。

这些值说明双向注意力可以训练，但最终仍接近均匀检索和恒定门控。v4.3 的主要有效成分仍是方向高频局部旁路；“先验证、再检索”只带来约万分之一量级的增益。

## 计算成本

| 方法 | 参数量 | 平均训练吞吐（样本/秒） |
|---|---:|---:|
| HF matched | 11,334,913 | — |
| 方向高频，无注意力 | 11,657,995 | 85.06 |
| 旧 v4.1 注意力 | 11,657,995 | 82.40 |
| v4.3 | 11,793,298 | 76.90 |

v4.3 比旧 v4.1 多约 1.16% 参数，训练吞吐降低约 6.7%；相对无注意力方向卷积降低约 9.6%。以当前结果看，这部分计算开销不能由 0.01%–0.02% 的精度增益支持。
