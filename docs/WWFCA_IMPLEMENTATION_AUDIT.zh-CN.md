# WWFCA 实现检查与修复记录

原理依据为项目根目录的 `3_ttas.md`，实现位于 `model/fdunet/fdunet_atten.py`。

## 已发现的问题

1. `unfold` 的输出布局为 `[B,C,nH,nW,M,M]`。旧代码未执行维度置换就直接变形为 `[B*4,C,M,M]`，造成窗口轴和通道轴的数据交叉，得到的并非原图中的完整局部窗口。
2. 窗口数量被写死为 4，窗口尺寸被写死为特征图边长的一半，只支持方形特征图和 2×2 个窗口。
3. 高、低频子带先放大到原窗口尺寸，再做注意力，与式（20）给出的 `M/2 × M/2` 子带尺寸不一致，同时使每个窗口的注意力矩阵扩大 16 倍。
4. Haar DWT 使用 `1/4` 系数。二维正交 Haar 变换应使用 `1/2`，旧实现不保持能量，四个子带的总能量只有输入的四分之一。
5. 式（24）要求注意力输出经过 LayerNorm 和 Dropout，旧实现没有后置 LayerNorm。
6. 代码用 `sqrt(N)` 猜测特征图尺寸，无法处理非方形特征图，也没有检查 token 数是否与空间尺寸一致。
7. 外部条件的 attention mask 被错误地用于内部小波 token；两者的 token 语义和长度并不相同。

## 修复后的数据流

对于 `[B,N,C]` 输入，`FDTransformer2DModel` 将真实 `(H,W)` 传给 WWFCA：

1. 恢复为 `[B,C,H,W]`，划分不重叠窗口；默认最大窗口 `M=8`，尺寸较小时自动选择可整除高宽的最大偶数窗口。
2. 正确排列为 `[B*nH*nW,C,M,M]`。
3. 用正交二维 Haar DWT 得到 `[B*nH*nW,C,M/2,M/2]` 的 LL、LH、HL 和 HH。
4. LL 展平为空间 token，作为 Query。
5. LH、HL、HH 沿通道拼接为 `3C`，作为 Key 和 Value。diffusers `Attention` 内部的 `to_q`、`to_k`、`to_v` 即式（22）的三个可学习线性投影。
6. 在每个窗口内部、`M/2` 分辨率执行交叉注意力，再按式（24）执行 LayerNorm 和 Dropout。
7. 将输出恢复到 `M×M`，按原空间位置合并所有窗口，再与 Transformer 残差相加。

配置必须满足 `cross_attention_dim = 3 × C`。不满足时现在会立即给出明确错误，避免等到矩阵乘法时才出现难以定位的维度异常。

## 计算量变化

在同一个窗口内，注意力 token 数从旧实现放大后的 `M²` 降为小波域的 `M²/4`。注意力矩阵规模从 `M⁴` 降为 `M⁴/16`。各窗口作为 batch 独立计算，符合“窗口频分交叉注意力”的定义，也不会意外混合相邻窗口。

WWFCA 前面的空间自注意力仍负责同一特征层上的跨窗口关系；WWFCA 本身负责窗口内低频结构和高频细节之间的交互。

## 参数量和权重兼容性

修正后的默认模型参数量为：

| 变体 | 参数量 |
|---|---:|
| `wwfca_only` | 13,908,481 |
| `fdu`（DCC+WWFCA） | 13,909,633 |

新增参数来自式（24）的后置 LayerNorm。旧 WWFCA 的频带和窗口排列错误，原权重的语义也与新实现不同，因此 WWFCA 和 FDU 应从头训练，不能把旧 checkpoint 当作可比较结果继续训练。

## 验证

`tests/test_wwfca.py` 覆盖：

- 窗口划分与合并严格可逆；
- Haar DWT 能量守恒，常量输入的三个高频子带为零；
- 多窗口和非方形特征图；
- 交叉注意力前向、反向及有限梯度；
- 错误的 `cross_attention_dim` 能被明确拒绝；
- 完整 `FDTransformer2DModel` 的形状恢复。

同时重新执行了 diffusion 对比路径和 Chen HF 的已有回归测试。
