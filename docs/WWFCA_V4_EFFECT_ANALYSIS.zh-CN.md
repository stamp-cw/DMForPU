# WWFCA v4 效果分析

## 结论

WWFCA v4 分支已经参与训练，残差幅度也不再像 v3 那样塌缩，但它没有学会有效的空间频率选择。全局交叉注意力将高频值近似均匀平均，最终注入的主要是每个通道近似恒定的偏置。HF 主干在联合微调后可以吸收这类偏置，所以开启和关闭 WWFCA 的最终结果几乎相同。

因此，当前问题不是高频输入缺失，也不是门控过小，而是注意力输出丢失了高频的空间定位。

## 配对实验结果

两个模型都从同一个 HF epoch 299 权重开始，使用相同数据顺序、扩散噪声和固定验证种子。前 5 轮冻结 HF 主干，只训练 WWFCA；后 20 轮联合微调。

| 方法 | 最佳轮次 | 验证 U3-NRMSE | 六条件平均 U3-NRMSE | 六条件平均 SSIM |
|---|---:|---:|---:|---:|
| HF epoch 299 | 299 | 0.00715029 | 0.00767607 | 0.98149652 |
| WWFCA v4 off | 21 | 0.00628156 | 0.00647068 | 0.98596823 |
| WWFCA v4 | 21 | 0.00627815 | 0.00647069 | 0.98597997 |

v4 与 off 的测试平均 U3-NRMSE 只差 `3.3e-9`，可视为相同。相对 HF epoch 299 的明显改善在关闭 WWFCA 时同样存在，所以该改善来自额外的低学习率微调，不能归因于 WWFCA。

## 训练阶段提供的证据

前 5 轮只训练 WWFCA 时，off 模型保持不变，v4 的验证 U3-NRMSE 从 `0.00715481` 改善到 `0.00712435`。第 5 轮 v4 比 off 低 `4.38e-5`，说明分支确实能表达少量有用修正。

第 6 轮开放 HF 主干后，off 立即达到 `0.00662479`，反而略好于 v4 的 `0.00663396`。第 6 至 25 轮两者差值的平均值只有 `-5.35e-8`。这说明主干很容易通过普通卷积学习同样的修正，WWFCA 没有提供主干难以替代的频率信息。

门控和残差均未塌缩：

- `gamma` 从 0.020 增长到约 0.02484；
- 注入残差与原下采样输出的 RMS 比值约为 0.78% 至 0.83%；
- 分支幅度已经接近设定的 1% 能量约束，因此简单增大门控不是合适的修复方向。

## 最佳权重的参数行为

最佳权重显示模型主要学习了 Value 和输出投影，没有真正学习频率选择关系：

| 参数 | 相对初始化变化 |
|---|---:|
| Query 投影 | 1.14% |
| Key 投影 | 1.21% |
| Value 投影 | 8.08% |
| 输出投影 | 377.65% |
| 二维相对位置偏置 | 0.24% |
| 高频局部卷积系数 `eta` | 0.05% |

三个方向频带权重的均值分别为 `0.99980`、`0.99983`、`0.99985`，整体范围只有 `0.99843` 至 `1.00109`。模型几乎没有区分 LH、HL、HH 三个方向。

这与注意力熵的结果一致：训练日志中的归一化注意力熵约为 0.983，真实样本诊断为 0.993，1.0 表示完全均匀。Query 和 Key 没有形成尖锐、位置相关的匹配。

## 真实 GFS 样本的特征诊断

在最佳权重、扩散时间步 500 的真实 GFS 样本上：

| 量 | 数值 |
|---|---:|
| LL RMS | 4.8891 |
| LH RMS | 3.3542 |
| HL RMS | 2.9620 |
| HH RMS | 2.5739 |
| 注入残差/主分支 RMS | 0.8288% |
| 注意力熵 | 0.9928 |
| 注意力输出的空间变化能量占比 | 0.2977% |
| 注入残差与主分支余弦相似度 | -0.0169 |

高频子带分别具有 LL 的 68.6%、60.6% 和 52.6% RMS，因此 DWT 后存在充足高频信息。然而注意力输出去除空间均值后只剩约 0.3% RMS，说明几乎所有空间高频结构都在全局 Softmax 聚合中被平均掉了。

## 原因排序

1. **全局注意力过于均匀。** 256 个 Key/Value token 被近似平均，输出趋向全局通道均值。
2. **高频位置没有直接通路。** 当前输出只有 `Attention(Q,K,V)`，没有保留 `H_c` 的同位置残差；一旦注意力均匀，高频空间结构便不可恢复。
3. **频带过早混合。** LH、HL、HH 先拼接再用一个 1×1 卷积压缩，且频带权重几乎不变，三个方向没有形成独立作用。
4. **训练目标只优化干净图像 MSE。** 没有对子带、梯度或边缘的直接约束，普通 HF 主干可以更容易地降低该损失。
5. **联合微调的主干学习率仍足以覆盖分支贡献。** 实验已经证明主干开放一轮后即可追平前五轮的 adapter-only 收益。
6. **只在一个 32→16 位置注入。** 单点模块表达能力有限，但在解决空间平均问题前，增加更多插入点只会增加成本。

## 建议的 v4.1 最小修改

保留“全局、不划窗口、LL 查询卷积高频、不使用 IDWT、残差注入”的核心思想，优先修改注意力输出形式：

1. 三个频带分别卷积，再拼接融合：

   `H_i = Conv_i(H_i), i in {LH, HL, HH}`

   `H_c = Conv_1x1(Concat(H_LH, H_HL, H_HH))`

2. 使用 LL 查询高频，但把注意力结果作为高频门控，而不是直接替代高频：

   `A = CrossAttention(Q=LL, K=H_c, V=H_c)`

   `G = sigmoid(Conv(A))`

   `Z = Conv_out(H_c * (1 + alpha * G))`

   `Y = B + gamma * Z`

   这样即使注意力早期较均匀，`H_c` 的同位置高频信息仍能到达输出；注意力负责选择和增强，而不是承担全部重建。

3. 为全局注意力加入可学习温度和二维距离先验。仍然允许任意位置互相注意，但初始化时更重视相近位置：

   `A = Softmax(tau * cosine(Q,K) + B_rel - beta * distance)`

   对 `tau` 和 `beta` 设置有界参数，避免注意力再次变成均匀平均或单点塌缩。

4. 增加轻量高频监督：对预测干净相位和真值的 LH、HL、HH 使用 L1 损失，权重先取 `0.01`，并单独记录该项，防止它主导原扩散目标。

5. 训练时先进行 10 至 15 轮 adapter-only；联合微调阶段把 HF 主干学习率从 `1e-5` 降到 `1e-6`。只有 v4.1 在冻结主干时稳定优于固定 HF，并在联合微调后仍优于 off，才进行多随机种子验证。

暂时不建议提高 `gamma`、放宽 1% 能量阈值或增加更多 WWFCA 插入层。当前分支已经具有足够幅度，首先需要让这部分能量携带位置相关的高频信息。
