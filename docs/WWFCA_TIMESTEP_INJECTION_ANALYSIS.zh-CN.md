# WWFCA 时间步残差注入分析

## 当前实现是否包含时间步控制

当前 v4.1 具有两种隐式时间步条件：

1. DWT作用于HF U-Net编码器特征，该特征已经受到U-Net timestep embedding影响；
2. timestep embedding与`log1p(sigma)`拼接后，通过FiLM调制高频特征。

但最终注入系数是所有时间步共享的单一参数：

`Y_t = B_t + gamma Z_t`，

其中最佳权重的`gamma≈0.02938`，不会随`t`变化。因此当前结构能改变每一步残差的内容，却不能显式控制每一步注入强度。

## 实际5步轨迹

5步DDPM使用时间步`800、600、400、200、0`。在clean样本的真实采样轨迹上：

| timestep | 内部残差/主分支 RMS | 对最终x0预测的相对影响 |
|---:|---:|---:|
| 800 | 2.41% | 0.545% |
| 600 | 2.75% | 0.637% |
| 400 | 2.64% | 0.566% |
| 200 | 2.53% | 0.422% |
| 0 | 2.62% | 0.457% |

虽然内部幅度相近，但DDPM更新对不同时间步的最终影响并不相同。各步分支输出的两两余弦相似度为`0.967～0.998`，方向高度一致，没有明显正负抵消。

## 单步注入诊断

使用同一个训练好的v4.1主干，只允许某一个推理步启用WWFCA，32张样本结果如下。

### 0 dB

| 启用位置 | U3-NRMSE |
|---|---:|
| 全部关闭 | 0.01081967 |
| 只在t=800启用 | 0.01081966 |
| 只在t=600启用 | 0.01082498 |
| 只在t=400启用 | 0.01082030 |
| 只在t=200启用 | 0.01080322 |
| 只在t=0启用 | 0.01066906 |
| 五步全部启用 | 0.01066081 |

### clean

| 启用位置 | U3-NRMSE |
|---|---:|
| 全部关闭 | 0.00729122 |
| 只在t=800启用 | 0.00729019 |
| 只在t=600启用 | 0.00729077 |
| 只在t=400启用 | 0.00729185 |
| 只在t=200启用 | 0.00727573 |
| 只在t=0启用 | 0.00712577 |
| 五步全部启用 | 0.00712040 |

最后`t=0`一步贡献了五步总改善的约95%～97%。早期三步几乎没有收益，个别条件轻微变差；`t=200`有少量作用。五步全部启用仍略好于只启用最后一步，所以不存在明显的“多步平均抵消”，但当前共享gamma把计算和残差预算浪费在了贡献很低的早期步骤。

## 原因

当前扩散模型使用`prediction_type="sample"`，网络直接预测干净`x0`。在DDPM最后`t=0`更新时，最终输出高度依赖最后一次干净图像预测；早期预测主要影响中间轨迹。因此即使每一步使用相同gamma，它们对最终结果的有效权重也不相同。

## 建议结构

增加显式、可解释的时间步与噪声门控：

`gamma(t,sigma) = gamma_max sigmoid(a + softplus(b)(1-t/T) - softplus(c)log1p(sigma))`。

约束含义：

- `softplus(b)≥0`：越接近采样后期，频率残差越强；
- `-softplus(c)log1p(sigma)`：输入噪声越强，越抑制高频注入；
- `gamma_max`继续限制最大残差，避免失控。

初始化时令`b`和`c`接近0，并令`a`复现当前`gamma≈0.029`，这样新模型起点与当前权重近似一致，新增收益只能来自学习到的时间/噪声分配。

不建议使用无约束MLP直接生成gamma。当前数据量和效应量较小，简单单调函数更容易解释，也便于消融。

## 必要消融

所有组保持原HF x0 MSE不变：

1. 共享常数gamma；
2. 只使用时间门控`gamma(t)`；
3. 时间与输入噪声联合门控`gamma(t,sigma)`；
4. 仅最后一步启用的推理控制组。

同时报告每个推理时间步的gamma、残差RMS、0 dB与clean指标。只有第2或第3组在严格训练对照下优于共享gamma，才能证明显式时间步控制有效。
