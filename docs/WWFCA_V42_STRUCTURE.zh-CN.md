# WWFCA v4.2：时间步与噪声控制的频率残差注入

## 改动范围

v4.2完整保留v4.1的DWT、三个方向独立卷积、LL查询高频、空间高频直达路径和全局交叉注意力，只把所有时间步共享的常数`gamma`改为逐样本门控`gamma(t,sigma)`。

损失函数保持HF原始干净`x0`预测MSE，不增加任何辅助损失。残差能量仅记录，不加入损失。

## 门控定义

定义采样进度：

`p(t) = 1 - t / 999`。

定义输入噪声量：

`n(sigma) = log1p(sigma)`。

联合门控为：

`gamma(t,sigma) = 0.1 sigmoid(a + b p(t) - c n(sigma))`，

其中`b,c≥0`，并通过有界sigmoid参数化到0至4。

- 越接近`t=0`，`p(t)`越大，残差注入越强；
- 输入噪声越大，残差注入越弱；
- 最大注入权重始终小于0.1；
- 初始`b=c=0.05`，使模型起点接近v4.1的常数gamma。

## 两个训练版本

| 方法 | 门控 |
|---|---|
| `wwfca_v41` | 共享常数gamma，已有基线 |
| `wwfca_v42_time` | `gamma(t)`，只使用时间步 |
| `wwfca_v42` | `gamma(t,sigma)`，联合使用时间步和输入噪声 |

三个方法均从同一个HF epoch 299权重开始，采用15轮adapter-only和20轮联合微调，损失、随机种子、数据顺序、扩散噪声及验证种子相同。

## 初始门控检查

五步采样`t=800、600、400、200、0`时，时间门控初始gamma约为：

`0.02016、0.02032、0.02048、0.02065、0.02081`。

在0 dB输入上，时间与噪声联合门控约为：

`0.01956、0.01972、0.01988、0.02004、0.02020`。

因此初始化只施加很弱的单调先验，主要时间与噪声强度仍由训练学习。

## 验证指标

除统一相位指标外，每轮额外记录：

- `gamma`均值、最小值和最大值；
- 时间控制强度`b`；
- 噪声控制强度`c`；
- 残差/主分支RMS；
- 注意力熵和空间门控标准差。

主要判定依据仍为验证集U3对齐NRMSE和六条件测试平均U3对齐NRMSE。只有v4.2相对v4.1共享gamma基线取得稳定改善，才能说明显式时间步控制有效。
